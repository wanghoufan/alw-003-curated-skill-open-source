## 使用

这些 Skill 遵循 `SKILL.md` 格式。当前仓库为私有，使用者和智能体需要有仓库读取权限。各客户端的安装方式以其官方 Skill 加载机制为准。

## 收录说明

优先选择能解决反复出现的问题、脱离作者私人环境仍可使用、且来源与再分发权利清楚的 Skill。个人账号资料、内部管家流程、机器专属路径和私密项目数据不纳入精选版本。仓库尚未确定许可证；未经许可不得复制、再分发或公开其中内容。
